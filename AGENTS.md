# Project-GT+++ — контекст для ИИ-агентов

Собственный GregTech-подобный мод для Minecraft **NeoForge 1.21.1**, написан с нуля (не аддон и не форк).
Долгая прогрессия по тирам, глубокие цепочки переработки. Mod id `projectgt`, пакет `com.vgst54.projectgt`.
Репозиторий: github.com/Vegstor54/projectgt-. Автор — Vegstor54.

## Как со мной работать

## Сборка и датагенерация

- `./gradlew build` — сборка, `./gradlew runClient` — игра, `./gradlew runData` — датагенерация.
- Модели, лут, теги, рецепты и английский ланг **генерируются** (`datagen/DataGenerators.java`).
  После добавления материалов, предметов или блоков нужен `./gradlew runData`, результат из `src/generated` коммитится.
- Ланг только английский. Тексты задаются в `DataGenerators.ModLang`, а не руками в json.
- Текстуры предметов материалов серые, цвет задаётся тонировкой в `ProjectGTClient` (`RegisterColorHandlersEvent`).

## Структура кода (`src/main/java/com/vgst54/projectgt/`)

- `material/` — `Materials` (список материалов), `Material` (record: цвет, набор иконок, формы, точка плавления,
  параметры инструментов), `MaterialForm` (dust, ingot, plate, rod, bolt, screw, gear...), `IconSet`, `Heat`, `ToolStats`.
  Минерал-руда добавляется строкой `ore("id", "Name", цвет, IconSet)`.
- `registry/` — `ModItems` (предметы материалов и инструментов, цикл по материалам), `ModBlocks` (руды создаются
  автоматически для пары материал × тип камня, трубы), `ModCreativeTabs`, `ModBlockEntities`.
- `item/` — `ToolType` (16 типов инструментов), `MaterialTier`, `CraftingToolItem`, `WrenchItem`.
- `pipe/` — жидкостные и предметные трубы, сетка ключа 3×3 (`PipeWrenchGrid`), блок-сущности.
- `worldgen/` — генерация руд: сетка 7×7 чанков (как в GregTech), сдвиг центра до 20 блоков, тип по весам,
  состав жилы в процентах (`OreNodes`, `OreNodeFeature`, `OreLookup`, `TerrainProbe`, `Vein`, `Mix`).
  Отладка: `/projectgt veins`. Ванильная генерация руд выключена в конфиге по умолчанию.
- `client/` — `WrenchOverlay` (сетка ключа), `ToolTooltips` (описания инструментов).
- `datagen/DataGenerators.java` — все провайдеры данных.

## Принятые дизайн-решения

**Руды и мир**
- Генерация без привязки к биомам и климату (интеграция с TFC возможна позже).
- Реальные минералы (касситерит, халькопирит, лимонит, магнетит и т.д.). Жила — смесь минералов, не больше 4 в одной.
- Железо и медь используют ванильные сырые предметы (без дубля raw ore). Бронза — сплав, делается крафтом.

**Прогрессия**
- Каменный век: мелкие поверхностные месторождения, руда падает крупицами. Затем бронза.
- Первый паровой котёл из бронзы по образцу GT: мало пара, долгий нагрев, медленное горение.
- В паровом веке пробоотборный бур с керном находит глубокие жилы. Неисчерпаемые жилы — потом.
- Цепочка инструментов как в GT: ступка → кувалда → напильник → отвёртка → ключ → кусачки.

**Трубы**
- Сначала жидкостные, затем предметные; механики по GTNH wiki (Fluid & Item Pipes). Значения маршрутизации
  предметных труб в стиле GTNH (restrictive pipe ×100).
- Ключ: сетка 3×3 на грани, центр переключает грань, боковые клетки соседние стороны. Shift+ПКМ ставит стрелку
  (жидкостные) или restrictive-режим (предметные). Та же система потом переедет на машины.

**Инструменты**
- Отдельный предмет на каждую пару материал × тип (не Data Component). Инструменты только из твёрдых материалов:
  у материала должен быть `withTool(new ToolStats(...))` (железо, медь, бронза, сталь, дерево). Олово и другие мягкие — нет.
- Типы: hard hammer, screwdriver, saw, crowbar, wire cutters, wrench, file, mortar, knife, scythe, soft mallet,
  pickaxe, axe, shovel, hoe, sword. Soft mallet только из неметаллов (дерево). Вантуз отложен до резины.
- Красится только оголовье (слой 1), рукоять (слой 0) нет. Ключ и монтировка целиком металлические (один слой 0 красится
  весь), хват монтировки красится красителем (`DYED_COLOR`, тег `minecraft:dyeable`). У ступки каменная чашка
  (слой 0) и металлический пестик (слой 1).
- Ручные инструменты теряют 1 прочность за крафт (`CraftingToolItem`), ключ — за каждое действие с трубой.
  Теги `projectgt:tools/<тип>` нужны рецептам.
- Дерево как материал: dust (опилки), plate, rod, bolt, screw, gear, small gear, без двойных пластин.
